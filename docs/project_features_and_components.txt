GHMC Grievance Portal - Project Features & UI Components
======================================================
Below is a comprehensive list of all the features, services, and UI components currently implemented in the React/Firebase web application.

------------------------------------------------------
1. Global Features & Architecture
------------------------------------------------------
* Frontend Framework: React (built with Vite)
* Styling System: Tailwind CSS for responsive, modern, and utility-first styling.
* Routing: React Router (Protected and Role-based navigation).
* Database & Backend: Firebase Firestore (NoSQL database).
* Storage: Firebase Storage (for uploading image evidence).
* Authentication: Firebase Auth (Email/Password with Citizen and Admin role management).
* AI Integration: Google Gemini Multi-modal AI natively wired into the React frontend.
* Icons & Visuals: Lucide React (SVG icons), Recharts (data visualization), Leaflet (maps), and Framer Motion (animations).

------------------------------------------------------
2. Core UI Components (frontend/src/components/)
------------------------------------------------------

[InteractiveBackground.jsx]
* Feature: A visually stunning, globally persistent background.
* UI Details: Uses framer-motion to create soft, pastel-colored fluid gradients that slowly follow and track the user's mouse cursor across the entire application.

[Auth.jsx]
* Feature: Unified Login & Registration Portal.
* UI Details: Sleek, glassmorphic cards using Framer Motion to animate transitions between the "Login" and "Sign Up" tabs. Features input validation, Firebase integration, and a hidden/interactive toggle to allow Admin registration.

[CitizenDashboard.jsx]
* Feature: The primary hub for standard users.
* UI Details: A clean, translucent dashboard that allows citizens to navigate between submitting a new civic issue and tracking the status of their existing ones. 

[GrievanceForm.jsx]
* Feature: A highly advanced, AI-powered submission form.
* UI Details:
  - Form validation for Category, Description, and Location.
  - Geolocation API: "Auto-Locate" button uses the browser's GPS to find exact coordinates.
  - Image Uploads: Allows users to attach photo evidence, which is uploaded directly to Firebase Storage.
  - Voice Dictation: Uses the browser's Web Speech API to let users speak their complaint instead of typing.
  - Instant Gemini AI Analysis: Automatically sends uploaded images to Google Gemini to auto-generate a professional written description. It also intercepts raw audio dictation and sends it to Gemini to clean up messy speech into a professional civic report. Features shimmering loading overlays while the AI thinks.

[GrievanceList.jsx]
* Feature: Citizen's history and tracking board.
* UI Details: Fetches a real-time list of the citizen's submitted complaints from Firestore. Displays them as elegant cards with color-coded status badges (e.g., Pending, In Progress, Resolved).

[AdminDashboard.jsx]
* Feature: The command center for city administrators.
* UI Details: Uses a translucent glassmorphic tabbed interface to organize wide-scale city data.
  * Tab 1: "Data Board" -> A comprehensive data table listing ALL grievances submitted across the city. Allows admins to review AI summaries and click a button to mark issues as "Closed/Resolved", updating the database instantly.
  * Tab 2: "Analytics" -> Uses `recharts` to render interactive data visualizations. Includes a Bar Chart showing which categories have the most complaints (e.g., Sanitation vs Roads) and a Pie Chart showing the resolution status across the city.
  * Tab 3: "Map View" -> Uses `react-leaflet` to drop geographic map pins of grievances based on their GPS coordinates, allowing admins to see "hotspots" of city issues.

------------------------------------------------------
3. Core Services (frontend/src/services/)
------------------------------------------------------

[aiService.js]
* Feature: Google Gemini AI SDK Wrapper.
* Details: Manages the connection to the `gemini-1.5-flash` model. Contains helper functions specifically crafted for the civic portal: `analyzeImageForGrievance` (multi-modal vision analysis) and `enhanceGrievanceAudioText` (text-based grammar and formatting cleanup).

[firebase.js]
* Feature: Backend SDK Initialization.
* Details: Securely connects the React frontend to the Google Firebase project. Exports `db`, `auth`, and `storage` modules used by all the components above.
