PROJECT OVERVIEW
----------------
CivicTrust (formerly CGTA) is a civic grievance platform for India built on
React + Vite with Firebase backend. It supports three user roles:
  - Citizen      → submits and tracks grievances
  - Field Officer → resolves assigned complaints with geotagged photo proof
  - Admin        → manages all complaints, analytics, TPA arbitration

Firestore collection: "complaints"
User roles stored in: "users/{uid}.role" (values: citizen / officer / admin)
Firebase path: frontend/src/firebase.js (never modified)

ARCHITECTURE NOTES
================================================================================

Firestore collection: "complaints" (NOT tickets, NOT grievances)
User roles in:       "users/{uid}" → { role: 'citizen'|'officer'|'admin' }

Grievance lifecycle:
  Submitted → Assigned (officer set) → In Progress → Resolved
  → Awaiting Citizen Confirmation
  → [Citizen Confirms] → Closed
  → [Citizen Rejects ×1] → In Progress (back to officer)
  → [Citizen Rejects ×2] → TPA_REVIEW (independent auditor)
  → [Admin Force Close] → Closed (closedByTPA: true)

Anti-fraud layers:
  1. EXIF Software tag check   — blocks edited images on upload
  2. Haversine GPS distance    — blocks resolution photos > 100m from site
  3. TPA escalation            — 2-strike rejection triggers auditor review
