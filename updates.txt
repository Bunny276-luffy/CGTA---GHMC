FIRESTORE DATA ARCHITECTURE
================================================================================

  Collection:  "complaints"
  User roles:  "users/{uid}" → { role: 'citizen' | 'officer' | 'admin' }

  Ticket lifecycle:
    Submitted
      → Assigned       (officer set)
      → In Progress
      → Resolved
      → Awaiting Citizen Confirmation
      → [Citizen Confirms]  → Closed
      → [Citizen Rejects ×1] → In Progress (back to officer)
      → [Citizen Rejects ×2] → TPA_REVIEW (independent auditor)
      → [Admin Force Close]  → Closed (closedByTPA: true)

  Anti-fraud layers:
    1. EXIF Software tag check   — blocks edited/manipulated images on upload
    2. Haversine GPS distance    — blocks officer resolution photos >100m from site
    3. TPA escalation            — 2-strike rejection triggers auditor review
